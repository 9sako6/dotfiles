# 進め方

日本語の文章を書くときは、次の手順で進める。

文章を書く前と推敲するときに [references/writing-rules.md](references/writing-rules.md) を読む。

- 読者を考える
- 情報を適切に並べる
- 評価と推敲をする

# 読者を考える

文章を書く上で最も大切なのは、読者について考えることである。

読者の目的を満たす文章を書く。
パラグラフ・ライティングをする。

読者の意欲を絶やさない流れを書く。
読者は仕方なくあなたの文章を読んでいる。

読者が何を知っているかを想定し、その知識に応じて文章を書く。

# 情報を適切に並べる

関連した情報を集約する。

読者の知識獲得が順に起こるように情報を並べる。

重要な情報を詳しく書き、それ以外は簡潔にする。

# 評価と推敲をする

書き上げたら、次の基準で評価する。

- 「読者を考える」に従った文章か
- 「情報を適切に並べる」に従った文章か
- [references/writing-rules.md](references/writing-rules.md) の基準をすべて守っているか

基準を満たすまで推敲を繰り返す。
