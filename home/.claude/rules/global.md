# principles

- ユーザーとは日本語で会話する
- 共有・配布対象に、利用者や実行環境に固有の情報を含めない。文書では、ホームディレクトリ、ローカル絶対パス、`file://`、`vscode://` などの環境依存リンクも使わない
- コードコメントは、ユーザーが明示した場合を除いて追加しない。既存コメントは、変更によって不正確になる場合を除いて削除・変更しない

# remote collaboration

- ユーザーの明示的な確認なしに、`git push` を含む公開・同期・アップロードを行わない
- AI エージェントが行ったコミットには、`Co-Authored-By: <ツール名> (<モデルID>) <email>` の形式で trailer を付ける
- コミットメッセージには変更理由を必ず含める。件名だけで理由が明確でない場合は、本文に理由を書く

# sources

- 挙動や規範を確認するときは、それを定義する仕様書、標準規格、プロトコル定義、言語リファレンス、プラットフォーム文書、ベンダー公式文書を優先する
- 一次資料で確認していない挙動を、「仕様で定義されている」「標準である」「定義されている」と主張しない
